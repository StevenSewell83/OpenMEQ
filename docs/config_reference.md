# OpenMEQ configuration reference

Generated by `scripts/gen_config_reference.py` from the live `openmeq.config.Config` pydantic schema -- **do not hand-edit**; re-run the generator instead (`python scripts/gen_config_reference.py`). `tests/test_config_reference.py` fails if this file is stale relative to the schema or the generator's own field-meaning text.

Every key below is documented, in the same order, in `config/example.yaml` -- the reference example config `openmeq.config.load_config` validates against. See [usage.md](usage.md) for what each pipeline step reads/writes, and [ARCHITECTURE.md](ARCHITECTURE.md) for the underlying contracts (§1 for the units convention, §3 for the run directory layout).

Every section is `extra="forbid"`: a misspelled or unknown key in your config raises a validation error naming the bad path, rather than being silently ignored. Any relative path value is resolved against *this config file's own directory*, not the process's current working directory.

A field's default is shown as `*(required)*` if the YAML must supply it explicitly (no schema default).
